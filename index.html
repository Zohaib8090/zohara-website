Arch-based Linux · KDE Plasma

A Linux that feels like home.

Zohara OS gives you a desktop you already know how to use: a familiar taskbar and Start menu, a Settings app laid out like Windows 11, a software store, and voice typing that runs entirely on your own computer.

Get Zohara OS See it

Free and open source. x86_64 PCs. Still being finished; see status.

Made for people coming from Windows

Linux is powerful, but it usually asks you to learn a new way of doing everything. Zohara keeps the parts you know and puts a button on the parts that used to need a terminal.

A desktop you already know

A taskbar with a Start button, a Start menu with search and Favorites, and a Windows-flavoured look on top of KDE Plasma. Nothing to relearn on day one.

Settings that change real things

A custom Settings app in the Windows 11 layout: display, sound, Bluetooth, network, storage, accounts, default apps, gaming and printers. Each page controls the actual system, not a mock-up.

Voice typing, fully offline

Press Meta + H, speak, and the words are typed where your cursor is. Recognition runs on your computer with whisper.cpp and a multilingual model that ships in the ISO. Nothing is uploaded.

A real software store

Zohara Store installs apps and handles updates. It shows what is changing, lets you choose what to update, and offers a way back if an update goes wrong.

Snapshots around updates

On Btrfs, a snapshot is taken before and after every package change, so there is something to go back to. Updates follow a date that the project approves, not the raw Arch stream.

Problems get reported, not hidden

If the installer fails, one button on the Welcome screen saves a report to a USB stick. In the installed system, Settings keeps a log and offers one-click fixes on the Troubleshoot page.

What is inside

  • Arch Linux base, with the KDE Plasma 6 desktop on Wayland.
  • The Zen kernel, tuned for desktop and gaming rather than servers.
  • NVIDIA open drivers included, so supported NVIDIA GPUs need no manual driver setup.
  • Brave Origin as the browser: Brave's ad and tracker blocking without the wallet, VPN or news.
  • The Calamares installer, which can install alongside Windows when it finds it.

Honest status

Zohara OS is still being finished. Some Settings pages don't respond yet, and the ISO is built from the latest development work. Please try it in a virtual machine or on a spare computer first.

Coming later: Zohara Link, a companion for Android that shares your clipboard, files and notifications with your PC. It is in development and not released.

Download

The ISO is about 3.9 GB, which is more than GitHub allows for a release file. So tagged versions are listed on the Releases page, and a fresh ISO is also built automatically every time the project changes.

Get the latest ISO

  1. Open the Releases page for tagged versions, or the latest successful build for the newest ISO (you need to be signed in to GitHub for builds).
  2. Download the zohara-os-x86_64 file. It is a zip that contains the .iso.
  3. Write the ISO to a USB stick with Ventoy, balenaEtcher or dd.
  4. Boot from the stick and choose Install Zohara, or Try Zohara to look around first.

Go to Releases Latest ISO build

A direct download link that doesn't need a GitHub account is planned. Build files are kept for 30 days.

Before you boot

  • Turn off Secure Boot. The bootloaders aren't signed yet.
  • If the installer shows no disks, set storage mode to AHCI instead of RAID / Intel RST.
  • On a PC with Windows, choose Install alongside or Manual partitioning. The installer never picks "Erase disk" for you.

System requirements

Minimum requirements
Processor64-bit x86 (Intel or AMD). Older CPUs work; voice typing is slower on them.
Memory4 GB RAM
Storage20 GB free
FirmwareUEFI or legacy BIOS
GraphicsIntel, AMD, or a modern NVIDIA card
