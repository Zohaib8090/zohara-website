06/Welcome
01Zohara Welcome

Install it, try it, or move in.

What you see on the live USB and the first time you sign in. Install Zohara, try it without installing anything, or move your files over from an old Linux install.

02Installing

An installer that asks first.

  • Calamares does the install, and can install alongside Windows when it finds it.
  • It never picks “Erase disk” for you.
  • Try Zohara boots the full desktop from the USB stick so you can look around before changing anything.
  • If the installer fails, one button on the Welcome screen saves a report to a USB stick.
Before you boot. Turn off Secure Boot, since the bootloaders are not signed yet. If no disks show, set the storage mode to AHCI instead of RAID / Intel RST.
03Moving in

Bring your files, safely.

Coming from another Linux install on the same computer? Welcome can move your files across, one at a time, and tells you which of your old apps have a Zohara equivalent.

A

Move, verify, delete

Each file is copied beside its destination, checked with SHA-256 against the original, renamed into place, and only then deleted from the old disk. Only one file’s worth of extra space is needed, so it works on nearly full disks.

B

Nothing is overwritten

If a file with the same name exists here, the old one is saved as “name (old system).ext”. An identical file is simply not copied twice.

C

A failed file stays put

A file that does not verify stays on the old disk. Old system files are only deleted when every file succeeded and you asked for it.

D

Apps translated

Debian and Ubuntu package names are matched to Arch packages, so the programs you used can be offered again.

E

Your own disk is protected

The old partition must not be mounted anywhere else, so the disk Zohara runs from cannot be picked by mistake.

04After the install

The first time you sign in.

  • Welcome shows once on an installed system, with shortcuts to migrate, to accounts and to updates (both in Settings).
  • Close it and it stays out of the way.
